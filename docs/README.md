### 🎯 Objetivos de Aprendizaje

Al completar estas guías, el alumnado será capaz de:

1. **Identificar** clases, objetos, atributos y métodos en código real
2. **Comprender** la encapsulación y modularidad
3. **Aplicar** conceptos de herencia y composición
4. **Refactorizar** código existente sin romper funcionalidad
5. **Documentar** código de forma clara y profesional

## 🚀 Cómo Usar Esta Documentación

### Para Profesorado
1. Revisar las guías antes de la clase
2. Adaptar ejercicios según nivel del grupo
3. Usar ejemplos del juego en explicaciones
4. Fomentar experimentación y creatividad

### Para Alumnado
1. **Ejecutar primero** → `00_poo_introduccion.ipynb` (Jupyter notebook)
2. **Leer después** → `01_intro_poo_con_julias_run.md`
3. **Practicar** → Ejecutar el juego y explorar código
4. **Mejorar** → Seguir `02_reto_mejoras.md`
5. **Documentar** → Crear tu propio README de mejoras

## 💡 Filosofía Pedagógica

> **"Aprender haciendo con código real"**

En lugar de ejemplos abstractos, usamos un **juego funcional** donde cada concepto de POO tiene una aplicación práctica y visible.

## 🔗 Conexiones Curriculares

- **Fundamentos de Programación**: Variables, funciones, control de flujo
- **POO**: Clases, objetos, encapsulación, herencia
- **Ingeniería de Software**: Modularidad, documentación, testing
- **Game Development**: Game loops, state management, event handling
