Friday13 font

This project can use the 'Friday13' font for the main title in the menu.
I can't download the font automatically due to network restrictions.

How to add the font locally:
1. Download the font from: https://www.dafont.com/es/friday13.font
2. Unzip (if necessary) and copy the TTF file to this folder:
   assets/fonts/friday13.ttf
3. Restart the game. The menu will use the font automatically if the file exists.

License note:
Please ensure you respect the font's license from Dafont. Some fonts are free for personal
use only; check the author's terms if you plan to distribute the game.
